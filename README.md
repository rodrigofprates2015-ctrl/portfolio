# Rodrigo Freitas — Portfolio

Site estatico pronto para Render.

1. Envie o conteudo desta pasta para um repositorio GitHub, GitLab ou Bitbucket.
2. No Render: New > Static Site e conecte o repositorio.
3. Build Command: echo "Static portfolio ready"
4. Publish Directory: dist
5. Create Static Site.

Alternativa: New > Blueprint, usando o render.yaml incluido.
Nao precisa de variaveis de ambiente ou backend.
